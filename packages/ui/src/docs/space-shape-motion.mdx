# Space, Shape & Motion

## Spacing

A 4px base scale where **the step number is the multiple** — `p-6` is 24px, `p-10` is 40px. Steps 1
to 12 run in fours, then 14, 16, 18, 20, 24, 32. Half steps `0-5` (2px) and `1-5` (6px) exist for
optical nudges only.

16 / 24 / 40 do most of the work.

### Layout

Content caps at 1200px (`--layout-container-max`). Gutters are 20px on mobile, 40px on desktop, and
`--layout-gutter-fluid` interpolates between them. Sections breathe: 56px vertical on mobile, 96px
on desktop.

| Token                      | Value                    | Used by                   |
| -------------------------- | ------------------------ | ------------------------- |
| `--layout-container-max`   | 1200px                   | `Container`               |
| `--layout-gutter-fluid`    | `clamp(20px, 4vw, 40px)` | `Container` padding       |
| `--layout-section-y-fluid` | `clamp(56px, 7vw, 96px)` | `Section` vertical rhythm |
| `--layout-header-h`        | 72px                     | `SiteHeader` (sticky)     |
| `--layout-tabbar-h`        | 64px                     | `TabBar` (fixed bottom)   |
| `--layout-hit-min`         | 44px                     | Every interactive target  |
| `--layout-card-min`        | 260px                    | `AutoGrid` minimum track  |

Grids are honest grids with `gap` — never masonry. Column counts run 1 → 2 → 3 → 4 → 4 across the
breakpoints, capped at the container width.

## Breakpoints

`sm` 480 · `md` 768 · `lg` 1024 · `xl` 1280 · `2xl` 1440.

**Every design must survive 360px** — that is narrower than the smallest breakpoint and it is the
floor, not a target. Check it in the `360 — smallest supported` viewport.

## Elevation

Shadows are warm-ink tinted and used sparingly. `shadow-brand` — the pink glow — is reserved for the
primary CTA and the floating cart button. Nothing else.

      <div className="font-body text-caption text-text-muted">{use}</div>

<div className="grid grid-cols-[repeat(auto-fit,minmax(min(160px,100%),1fr))] gap-8 rounded-4 bg-surface-page-alt p-8">
  <Shadow name="shadow-elevation1" use="card at rest" />
  <Shadow name="shadow-elevation2" use="raised control" />
  <Shadow name="shadow-elevation3" use="card on hover" />
  <Shadow name="shadow-elevation4" use="modal, sheet" />
  <Shadow name="shadow-brand" use="primary CTA only" />
</div>

**Cards.** Default: white fill, `rounded-4`, 1px `border-border-subtle`, `shadow-elevation1`; on
hover it lifts 2px to `shadow-elevation3`. Feature card: `brand-soft` fill, no border, no shadow,
`rounded-5`. Menu rows are not cards at all — a 1px rule between rows.

**No card ever has a coloured left border.**

## Motion

Short and matter-of-fact. Fades are always paired with a small translate — never opacity alone.

| Token                | Value | Used for                 |
| -------------------- | ----- | ------------------------ |
| `--duration-instant` | 80ms  | Press                    |
| `--duration-fast`    | 140ms | Hover                    |
| `--duration-base`    | 220ms | State changes            |
| `--duration-slow`    | 340ms | Sheets, page transitions |

| Easing          | Used for                                      |
| --------------- | --------------------------------------------- |
| `ease-out`      | Anything entering                             |
| `ease-in-out`   | Anything moving                               |
| `ease-entrance` | Sheets                                        |
| `ease-pop`      | Add-to-cart and reward confirmations **only** |

`ease-pop` has one overshoot. Using it anywhere else makes the UI bounce, which this brand does not
do.

### Durations, side by side

**Hover a track** — each dot travels the same distance on a different duration, so the difference is
something you feel rather than read.

### Reduced motion

The base layer honours `prefers-reduced-motion: reduce` globally: animations and transitions
collapse to instant. Keep the fade, drop the movement — no component needs to handle this itself.

To see it, turn on **Settings → Accessibility → Reduce motion** in macOS and reload: every specimen
above goes still, and nothing on this page breaks.
