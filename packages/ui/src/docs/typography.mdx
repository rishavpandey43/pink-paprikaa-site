# Typography

**Poppins** for everything structural — geometric, circular, tight tracking, matching the wordmark's
bowls. It carries Devanagari, so `पैप्रिका` and dish names set in the same family. **DM Sans** for
running text and UI. **Space Mono** for order codes and receipt lines only.

These are final. Do not substitute.

## The ramp

Every piece of text goes through the `Text` atom, which locks these twelve steps so nothing is
ad-hoc. Each step owns its size, line-height and tracking together — they are one decision.

## Fluid twins

Seven steps carry a `clamp()` twin: `display1` `display2` `h1` `h2` `h3` `subtitle1` `body1`.

**Set `isFluid` in every responsive layout.** Fixed sizes belong in type specimens and on marketing
canvases, where the artboard size is known. The small end of the ramp has no twin — it is already
comfortable at any width, and scaling it down would break the 44px hit-target floor.

```tsx
<Text isFluid variant="h1">
  Desi at heart. Urban by nature.
</Text>
```

## Rules

- Display sizes get negative tracking and line-height near 1.0. Body stays at 1.6.
- Overlines are Poppins Bold, uppercase, +0.14em — and are the **only** place ALL CAPS is allowed
  besides heat labels. Never a full sentence in caps.
- Headlines ≤ 6 words. Body sentences average 12 words, hard stop at 24. Menu descriptions ≤ 14
  words, ingredient-led.
- Cap line length with `measure`: `prose` (64ch) for long-form, `narrow` (44ch) for pull quotes.
- Headings balance across lines; running text avoids orphans. `Text` does this for you.
- Devanagari is reserved for the logo, big display moments and dish names — never for a control.
