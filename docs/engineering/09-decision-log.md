# 09 — Decision Log & Drift Ledger

Append-only. Every entry: what was decided, why, and — for rejections — the **reconsider
trigger** that reopens it. A decision without a written trigger is a taboo; taboos rot.
Sources: the reference-architecture review (a prior production codebase, extracted 2026-08-08,
gitignored as `docs/Reference_*.md`), and this repo's own build history.

## Design-system rewrite — spec decisions (2026-09-27)

Locked in [the design-system rewrite spec §3.1](../superpowers/specs/2026-09-27-design-system-rewrite-design.md),
one line each. The spec holds the rationale.

| #   | Decision                                                                                                                                            |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | Full rewrite of `packages/design-tokens` and `packages/ui`. Package names, Nx tags and workspace tooling stay.                                      |
| D2  | Scope is 100% of the design-system folder, plus the handoff's refinements and repeated patterns.                                                    |
| D3  | Brand fills stay the brand pink. Every text colour meets AA. White on the brand pink is the single declared exception, at the AA-large floor (3:1). |
| D4  | Token names mirror the design system 1:1, translated only into Tailwind v4 namespaces (`--fs-h4` → `text-h4`).                                      |
| D5  | Surfaces are CSS (`data-surface`), not props. No component takes an `on` prop.                                                                      |
| D6  | Server-first. `"use client"` only where a component owns state, effects or browser APIs. Hover, press and focus are CSS.                            |
| D7  | Native platform before libraries. Radix only for Dialog/Sheet, Tabs, Tooltip, Toast and ToggleGroup, plus Slot for `asChild`.                       |
| D8  | `asChild` (Radix Slot) on Button, IconButton, Link, Card, LinkCard, ListRow and the TabBar items.                                                   |
| D9  | No content inside the system: copy, links, brand facts and prices arrive as props.                                                                  |
| D10 | Icons come from `lucide-react`, passed as components. Three local brand glyphs cover Instagram, YouTube and LinkedIn (Lucide 0.408's own, ISC).     |
| D11 | Fonts are self-hosted: `@fontsource/*` in Storybook now, `next/font` in the apps at step 2.                                                         |
| D12 | Brand facts are a Zod-validated typed module in `packages/content`. The design system never imports it.                                             |
| D13 | Storybook is the design system's "Design System tab": 13 groups, in the design system's order.                                                      |
| D14 | The `templates/` layer is renamed `layouts/`. Atoms may import only `atoms/icon` (LAW).                                                             |
| D15 | Motion is CSS first. `motion` is not installed; adding it needs an entry here naming the component and the CSS limit it hit.                        |
| D16 | Storybook is local plus a static build. No hosting this phase.                                                                                      |
| D17 | Forms use react-hook-form + Zod. `packages/ui` stays RHF-compatible by contract, with no RHF dependency.                                            |
| D18 | `prettier-plugin-tailwindcss` owns class order (`tailwindFunctions: ["componentVariants"]`). ESLint's `classnames-order` is off.                    |

## Design-system rewrite — implementation rulings that changed a rule (Plan 1)

These IDs are rulings from the Plan 1 implementation ledger. They are distinct from the `R-nn`
reference-codebase rows above.

| #   | Ruling                                                                                                                                                                                  | Why                                                                                                                                                        |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R13 | Every optional custom prop is `?: T \| undefined`, matching React's DOM prop types.                                                                                                     | `exactOptionalPropertyTypes` is on, and compositions forward values that may be `undefined`.                                                               |
| R15 | Every test or spec that reads a file builds the path with `join(import.meta.dirname, …)`, never `new URL(…, import.meta.url)`.                                                          | Under jsdom, Vite rewrites the `URL` form into an `http://localhost` asset URL.                                                                            |
| R19 | The brand symbol is one shared CSS mask (`--pp-symbol-mask` and `@utility mask-symbol`, in `packages/ui/src/lib/brand-artwork.css`). Never inline SVG per instance.                     | Inline path data per diamond would add ~400 KB to a menu page.                                                                                             |
| R21 | Text-entry controls render their value at 16px.                                                                                                                                         | iOS zooms on focus below 16px, and the handoff uses 16px. The cost is 1px over the design-system card's 15px.                                              |
| R23 | `pink-paprikaa/no-arbitrary-shorthand` bans `w-(--x)` and `[prop:value]` classes, and the atom rule also catches roundabout paths (`../../atoms/x`, `../../index`).                     | `tailwindcss/no-arbitrary-value` only catches `-[…]`, and the handbook's own canonical example used the shorthand (03 §1 now shows the real `Button`).     |
| R25 | Brand artwork is compiled at svgo path precision 2 (lockup ≈ 23.4 → 14.8 KB gzipped). There is no JS symbol data-URI export. Logo is sized by classes only (no `width`/`height` props). | Precision 1 visibly distorts the lotus ring around the "i" dots, and the brand forbids altering the logo. A data-URI export invited per-instance inlining. |
