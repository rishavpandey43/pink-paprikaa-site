# SDD records (verbatim archive)

Copies of the subagent-driven-development workspaces from `.superpowers/sdd/`, which git ignores: ledgers
(`progress.md`, every ruling and deferred item), task briefs, implementer reports, fix findings, audit
reports and visual evidence. They are archived here so the working records of the design-system rewrite are
never lost. Review diffs are left out, because `git diff <base>..<head>` regenerates them.

These are records, not guidance. For current rules, see `packages/ui/AUTHORING.md` and
`docs/engineering/`. The files are kept verbatim, so `.prettierignore` excludes this folder.
