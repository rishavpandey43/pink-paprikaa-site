# Layout rhythm

A content container, a fluid gutter, a fluid grid gap and fluid section spacing set the page's
rhythm. `Container` and `Section` apply them; the `container-page` and `section-y` utilities do the
same for raw markup.

The gutter runs 20px → 40px and section spacing 56px → 96px (the design system's layout rhythm).
Sections breathe: never less than the mobile section value, never more than the desktop one.
